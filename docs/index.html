Je persoonlijke code

  1. Zet deze code nu in je wachtwoordkluis. Hij wordt maar één keer getoond. Niemand anders heeft hem, ook de beheerder niet.
  2. Stuur deze zes controlewoorden in Teams naar de beheerder:Daarmee controleert de beheerder dat jouw aanmelding onderweg niet is aangepast.
  3. Na goedkeuring log je in met je uitnodigingscode en deze code.

Je bent al aangemeld

Log in met je code van zes woorden. Ben je je code kwijt? Maak dan een nieuwe aan. Je scores en voortgang blijven bewaard; je eigen antwoorden op open vragen niet.

Elke ochtend vanzelf je les

Laat je computer DoubleLeren openen zodra je inlogt. Eenmalig instellen, ongeveer een minuut.

Windows

  2. Druk op Windows + R, typ shell:startup en druk op Enter. De map Opstarten gaat open.
  3. Klik met rechts in die map → Nieuw → Snelkoppeling, plak de link, klik op Volgende, noem hem DoubleLeren en klik op Voltooien.

Mac

  2. Open Systeeminstellingen → Algemeen → Inlogonderdelen.
  3. Klik op + en kies DoubleLeren.webloc uit je Downloads.

De snelkoppeling opent alleen deze pagina. Vink bij het inloggen "Onthoud mij" aan, dan sta je meteen in je les.
